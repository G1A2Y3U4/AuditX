# AuditX – Automated College Auditing System

**An AI-powered platform for automating college auditing workflows and document verification.**

## 📌 About the Project

AuditX is a web-based college auditing system designed to simplify and automate the document verification process. The platform aims to reduce manual auditing effort by comparing uploaded documents against approved templates using AI-based document analysis.

Based on the comparison results, the system supports automated document approval or rejection, helping make the auditing workflow more efficient and organized.

**Project Status:** Completed
**Project Type:** Team Project

## 🎯 Objectives

- Automate college auditing and document verification workflows.
- Reduce manual document verification efforts.
- Compare uploaded documents with approved templates using AI-based analysis.
- Support automated approval and rejection decisions.
- Provide secure user access through email authentication.
- Manage document storage using cloud services.

## ✨ Key Features

### 1. AI-Based Document Comparison
- Analyze uploaded documents against approved templates.
- Identify differences between submitted documents and reference templates.
- Support automated verification decisions.

### 2. Automated Document Verification
- Compare submitted files with approved reference documents.
- Support approval or rejection based on document comparison results.

### 3. Cloud Document Storage
- Integrate Cloudinary for document storage and management.
- Use Supabase for backend services and data integration.

### 4. Email Authentication
- Provide email-based user authentication.
- Support secure access to the application.

## ⚙️ Project Workflow

1. Users access the AuditX platform through email authentication.
2. Documents are uploaded to the platform.
3. Uploaded documents are compared against approved templates.
4. AI-based document analysis evaluates the differences.
5. The system supports an approval or rejection decision based on the verification results.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/G1A2Y3U4/AuditX
   ```

2. Navigate to the project directory:

   ```bash
   cd AuditX
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables in a `.env.local` file according to your Supabase and Cloudinary setup.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open your browser and visit:

   ```text
   http://localhost:3000
   ```

*Note: The installation commands assume a standard Next.js npm project. Adjust them if your repository uses different scripts.*
